# Notes for reviewers

## Why local feature layout

This feature is intentionally local to this repository under:

- `.devcontainer/src/mcp-genmedia`
- `.devcontainer/test/mcp-genmedia`

That keeps feature code, scenarios, and smoke validation close to the repository and easy to iterate on.

## Default install profile

The repo-level `.devcontainer/devcontainer.json` references local feature path `./src/mcp-genmedia` and defaults to avtool-first minimal installation:

- `installAll=false`
- `installAvtool=true`

Additional options are available for expanded installs.

## Optional profiles

### Install all

Use the test scenario `install-all` (or set `installAll=true`) to enable all optional install steps.

### Avtool-only

Use the test scenario `avtool-only` for the minimum POC footprint.

## Smoke test (Gemini + MCP readiness)

A helper script is available at `.devcontainer/test/mcp-genmedia/smoke-gemini-mcp.sh`.

Example:

```bash
export GEMINI_API_KEY="<your-key>"
.devcontainer/test/mcp-genmedia/smoke-gemini-mcp.sh
```

The script validates:

1. `gemini` exists
2. `avtool` exists
3. `~/.gemini/settings.json` has an MCP server entry
4. Optional check for `GEMINI_API_KEY` and a ready-to-run prompt command

Manual chat smoke flow:

1. Set `GEMINI_API_KEY` in your shell.
2. Run `gemini`.
3. Enter a simple Genmedia-oriented prompt that references the avtool MCP server (for example, requesting a basic image workflow plan).
